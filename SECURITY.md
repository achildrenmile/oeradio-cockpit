# Sicherheit

## Sicherheitsprobleme melden

Bitte **kein öffentliches Issue** anlegen. Nutze das private Meldeformular von GitHub
(Private Vulnerability Reporting): Reiter **Security** → **Report a vulnerability**.

Hilfreich sind: betroffene Komponente (Firmware, Aggregator, Deploy), Version oder Commit,
Schritte zum Nachstellen und die möglichen Auswirkungen. Bitte keine echten Zugangsdaten mitschicken.

## Unterstützte Versionen

Das Projekt ist in einer frühen Phase (v0.x). Korrekturen gibt es nur für den aktuellen Stand.
